# Этап 4: Чеклист ручного тестирования

**Дата:** 2025-10-31  
**Статус:** В процессе

## ✅ Чеклист для ручного тестирования

### 1. WebSocket подключение

#### Проверка в DevTools:
- [ ] Открыть DevTools → Network → WS (WebSocket)
- [ ] Проверить, что есть подключение к `ws://localhost:8080/api/ws/pets/{user_id}`
- [ ] Проверить, что подключение только **ОДНО** (не множественные)
- [ ] Проверить статус: **101 Switching Protocols** (успешное подключение)

#### Проверка в Console:
- [ ] Видно лог: `🔌 [WebSocket] Подключение к: ws://...`
- [ ] Видно лог: `✅ [WebSocket] Подключено`
- [ ] НЕТ множественных логов подключения
- [ ] Видно heartbeat (ping каждые 30 секунд, но без лишних логов)

---

### 2. Отключение polling

#### Проверка в Network tab:
- [ ] **НЕТ** частых запросов к `/api/summary/all?user_id=...`
- [ ] **НЕТ** частых запросов к `/api/summary?user_id=...`
- [ ] **НЕТ** частых запросов к `/api/economy/wallet/{user_id}`
- [ ] **НЕТ** частых запросов к `/api/market/auctions?status=active&...`
- [ ] Запросы есть только при **первой загрузке** или при **явных действиях**

#### Проверка интервалов:
- [ ] Если WebSocket подключен → polling **отключен** (нет запросов каждые 5-10 сек)
- [ ] Если WebSocket отключен → polling **включен** (запросы каждые 5-10 сек)

---

### 3. Обновления через WebSocket

#### Тест 1: Создание питомца
1. Создать нового питомца
2. Проверить в Console:
   - [ ] Видно лог: `📨 [WebSocket] Получено сообщение: pet_created`
3. Проверить в UI:
   - [ ] Новый питомец появился **мгновенно** (без перезагрузки)
   - [ ] **НЕТ** запроса к `/api/summary/all` в Network tab

#### Тест 2: Изменение здоровья
1. Нажать кнопку "Лечение" (health_up)
2. Проверить в Console:
   - [ ] Видно лог: `📨 [WebSocket] Получено сообщение: health_changed`
3. Проверить в UI:
   - [ ] Здоровье изменилось **мгновенно**
   - [ ] **НЕТ** запроса к `/api/summary` в Network tab

#### Тест 3: Переход стадии
1. Дождаться перехода стадии (или симулировать)
2. Проверить в Console:
   - [ ] Видно лог: `🔄 [WebSocket] Переход стадии: ...`
3. Проверить в UI:
   - [ ] Стадия изменилась **мгновенно**

#### Тест 4: Обновление кошелька
1. Выполнить действие, которое изменяет кошелек (например, health_up за монеты)
2. Проверить в Console:
   - [ ] Видно лог: `📨 [WebSocket] Получено сообщение: wallet_updated`
3. Проверить в UI:
   - [ ] Баланс монет обновился **мгновенно**

---

### 4. Redis кеширование (Backend)

#### Проверка ETag:
1. Открыть DevTools → Network
2. Найти запрос к `/api/summary/all`
3. Проверить:
   - [ ] В Response Headers есть `ETag: "..."`
   - [ ] При повторном запросе есть `If-None-Match: "..."` в Request Headers
   - [ ] Если данные не изменились → ответ **304 Not Modified**

#### Проверка кеширования:
1. Сделать запрос к `/api/summary/all`
2. Повторить запрос в течение 30 секунд
3. Проверить:
   - [ ] Второй запрос вернул **304 Not Modified** (если данные не изменились)
   - [ ] Или данные пришли быстро (из кеша Redis)

### 5. Производительность Phaser игр

#### Тест 1: Запуск игры без обновлений
1. Открыть игру (например, Pet Thief)
2. Проверить:
   - [ ] Игра запускается нормально
   - [ ] FPS стабильный (~60 FPS)
   - [ ] Нет тормозов

#### Тест 2: Игра + обновления данных
1. Запустить игру
2. В другой вкладке/окне изменить данные питомца
3. Проверить:
   - [ ] Игра **НЕ тормозит** при обновлениях
   - [ ] FPS остается стабильным
   - [ ] Нет блокировок

#### Тест 3: Игра + множественные обновления
1. Запустить игру
2. Быстро выполнить несколько действий (health_up, create pet, etc.)
3. Проверить:
   - [ ] Игра остается плавной
   - [ ] Нет лагов при множественных WebSocket сообщениях

---

### 6. Автоматическое переподключение

#### Тест 1: Отключение сервера
1. Остановить backend сервер
2. Проверить в Console:
   - [ ] Видно лог: `🔌 [WebSocket] Соединение закрыто`
   - [ ] Видно лог: `🔄 [WebSocket] Переподключение через ...мс`
3. Запустить backend сервер обратно
4. Проверить:
   - [ ] WebSocket переподключился автоматически
   - [ ] Видно лог: `✅ [WebSocket] Подключено`

#### Тест 2: Перезагрузка страницы
1. Перезагрузить страницу
2. Проверить:
   - [ ] WebSocket подключается автоматически
   - [ ] Данные загружаются через WebSocket

---

### 7. Fallback на polling

#### Тест: Отключение WebSocket
1. В Console выполнить: `globalWebSocket?.close()` (или другой способ отключения)
2. Проверить:
   - [ ] Polling **включился** автоматически
   - [ ] Видны запросы каждые 5-10 секунд к `/api/summary/all`
   - [ ] Приложение продолжает работать

- **ИТОГО:** ~2-3 запроса/мин
