# Встроенный Redis Addon от Render

## Что это такое?

**Встроенный Redis Addon от Render** — это управляемый (managed) сервис Redis, который Render предоставляет как отдельный ресурс. Это **не веб-сервис**, а специальный managed сервис, оптимизированный для Redis.

### Преимущества перед Docker контейнером:

✅ **Более надежный** - специально оптимизирован для Redis  
✅ **Автоматическое резервное копирование**  
✅ **Высокая доступность** - меньше простоев  
✅ **Внутренняя сеть** - быстрое подключение между сервисами  
✅ **Управление памятью** - автоматическое управление ресурсами  
✅ **Мониторинг** - встроенные метрики  

## Как это работает?

Render предоставляет **Key Value (Redis-compatible) instance**, который является полностью совместимым с Redis сервисом.

## Как получить Connection URL

После создания Key Value instance:

1. Откройте [Render Dashboard](https://dashboard.render.com)
2. Перейдите в **Key Value** → `telepets-redis`
3. Найдите секцию **"Connect"** или **"Connection Info"**
4. Скопируйте **Internal Redis URL**
5. URL должен быть в формате: `redis://red-xxxxx:6379` или похожий

**Важно:** Я уже обновил `REDIS_URL` в backend сервисе, но если подключение не работает, проверьте правильность URL в Dashboard и обновите при необходимости.

## Подключение к backend сервису

После создания Redis addon:

1. В backend сервисе (**telepets-api-docker**) обновите переменную окружения:
   ```
   REDIS_URL=redis://red-xxxxx:6379
   ```
   (где `red-xxxxx` - ваш Internal Redis URL)

2. Перезапустите backend сервис
