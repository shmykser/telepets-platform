# Telepets Mini Games - Архитектура и структура проекта

## 📋 Обзор проекта

**Telepets Mini Games** - это набор мини-игр на базе Phaser.js, интегрированных с Telegram WebApp. Проект реализует сложную игровую механику с открытым миром, системой краж, замков и множественными игровыми сценами.

### 🎯 Основные возможности:
- **Pet Thief** - основная игра с открытым миром и системой краж
- **Egg Defense** - защита яйца от врагов
- **Lockpicking** - система взлома замков (3 типа)
- **House Interior** - интерьер домов для краж
- **Тестовые сцены** - для разработки и отладки

**Назначение:** Точка входа в игру, навигация между сценами
**Ключевые особенности:**

**Загружает:**

- Фоновые текстуры
- Звуки и музыку
- UI элементы

**Назначение:** Главная игровая сцена с открытым миром

### 4. **EggDefense.js** - Защита яйца

## ⚙️ Игровые системы (Systems)

### 🎯 Core Systems (src/systems/core/)

#### **EventSystem.js** - Центральная система событий
**Назначение:** Event-Driven Architecture, паттерн Observer
**Возможности:**
- Подписка на события (`on`, `once`)
- Отправка событий (`emit`)
- Статистика событий
- Автоматическая очистка

**Пример использования:**
```javascript
// Подписка
eventSystem.on('pet:coinsCollected', (data) => {
    console.log(`Собрано монет: ${data.coins}`);
});

// Отправка
eventSystem.emit('pet:coinsCollected', { coins: 10 });
```

#### **PetControlSystem.js** - Управление питомцем
**Назначение:** Обработка кликов, движение питомца
**Функции:**
- Клик по миру → движение к точке
- Следование за курсором
- Взаимодействие с объектами
- Анимации движения

#### **MovementSystem.js** - Система движения
**Назначение:** Управление движением всех объектов
**Особенности:**
- Плавное движение с интерполяцией
- Коллизии и препятствия
- Различные типы движения

#### **AttackSystem.js** - Система атак
**Назначение:** Обработка боевых действий
**Функции:**
- Атаки по области
- Урон от времени
- Эффекты атак

#### **CollisionSystem.js** - Система коллизий
**Назначение:** Обработка столкновений
**Типы коллизий:**
- Объект-объект
- Объект-препятствие
- Триггерные зоны

### 🌍 World Systems (src/systems/world/)

#### **WorldGenerator.js** - Генератор мира
**Назначение:** Создание игрового мира
**Алгоритмы:**
- Perlin Noise для рельефа
- Процедурная генерация биомов
- Размещение объектов
- Создание дорог и троп

#### **WorldRenderer.js** - Рендерер мира
**Назначение:** Отрисовка игрового мира
**Функции:**
- Рендеринг фона
- Отрисовка препятствий
- Управление камерой
- Оптимизация производительности

#### **LocationGraphGenerator.js** - Генератор графа локаций
**Назначение:** Создание локационной системы v2.0
**Особенности:**
- Граф связанных локаций
- Переходы между биомами
- Процедурная генерация
- Сохранение состояния

### 🎭 Strategy Systems (src/systems/strategies/)

#### **Movement Strategies** - Стратегии движения
- `SimpleMovementStrategy.js` - простое движение
- `PathfindingMovementStrategy.js` - поиск пути
- `FleeingMovementStrategy.js` - убегание
- `PatrolMovementStrategy.js` - патрулирование

#### **Attack Strategies** - Стратегии атак
- `SimpleAttackStrategy.js` - простая атака
- `SpawnAttackStrategy.js` - атака с появлением
- `SingleUseAttackStrategy.js` - одноразовая атака

#### **Detection Strategies** - Стратегии обнаружения

## 📝 Примечания для разработчика

### **При доработке PetThiefScene:**
1. **Получение параметров:** Используйте `getPetDataFromURL()` для получения данных питомца
2. **Сохранение прогресса:** Интегрируйте с API через `gamesApi.saveProgress()`
3. **Имена пользователей:** Получайте через `gamesApi.getUserNames()`
4. **Завершение игры:** Отправляйте `postMessage` родительскому окну

### **Ключевые файлы для модификации:**
- `PetThiefScene.js` - основная логика игры
- `WorldRenderer.js` - отрисовка домов с именами
- `PetControlSystem.js` - управление питомцем
- `EventSystem.js` - обработка событий игры

### **Архитектурные принципы:**
- Event-Driven Architecture
- Модульная структура
- Разделение логики и представления
- Адаптивный дизайн
- Оптимизация производительности
