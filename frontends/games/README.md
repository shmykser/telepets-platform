# Telepets Games (vNext)

Новый фронтенд-пакет для мини-игр Telepets. Он переосмысляет старый Phaser-проект (`games_old`) и готовится к тесной интеграции с `frontends/webapp`.

## Цели

- унифицированный стек: React 19 + Vite 7 + Phaser 3.90;
- повторное использование UI-токенов и интеграция с темой WebApp;
- модульный перенос игровых систем из `games_old`;
- прозрачная коммуникация с основным приложением через `postMessage`.

## Скрипты

```bash
npm install
npm run dev      # http://localhost:5174/ (приложение живёт под /games/)
npm run build    # production build -> dist/
npm run preview  # предпросмотр готовой сборки
npm run lint     # ESLint для src/**/*.ts(x)
```

## Структура

- `src/` — точка входа React, обёртка над Phaser и будущие игровые модули.
- `src/phaser/` — конфигурация Phaser и базовые сцены.
- `src/integration/` — коммуникация с WebApp.
- `src/config/settings.ts` — единый конфиг проекта (обязательно дополняем при добавлении глобальных переменных).
- `games_old/` — сохранённый предыдущий проект, используем как reference.

### Навигация

- `/games/` — каталог сцен (карточки со статусами и стадиями).
- `/games/:sceneSlug` — запуск сцены. При наличии `defaultStage` произойдёт автоматический редирект.
- `/games/:sceneSlug/:stage` — конкретная стадия (например, `/games/egg/temperature`).
