# Чек-лист тестирования мобильной верстки

## Основные принципы
- Mobile-first подход (Tailwind CSS)
- Touch targets минимум 44x44px
- Safe-area поддержка для iOS
- Предотвращение горизонтального скролла
- Фиксированные элементы должны оставаться на месте

## 1. Viewport и Safe Area
- [ ] Viewport meta tag настроен правильно
- [ ] Safe-area-inset учитывается для bottom padding
- [ ] Контент не перекрывается системными элементами (notch, home indicator)

## 2. Размеры экрана (iPhone SE, iPhone 12 Pro, iPhone 14 Pro Max, iPad)
- [ ] iPhone SE (375x667) - самый маленький экран
- [ ] iPhone 12 Pro (390x844)
- [ ] iPhone 14 Pro Max (430x932)
- [ ] iPad (768x1024)
- [ ] Galaxy S20 Ultra (412x915)

## 3. Блок статистики и кнопка "Создать питомца"
- [ ] Оба элемента помещаются в одну строку
- [ ] Каждый элемент занимает 50% ширины (w-1/2)
- [ ] Элементы не выходят за границы экрана
- [ ] Нет горизонтального скролла
- [ ] Отступы между элементами корректные (gap-2)

## 4. Карусель питомцев (PetCarouselEnhanced)
- [ ] Карусель не выходит за границы экрана
- [ ] Карточки питомцев полностью видны
- [ ] Нет горизонтального скролла на уровне body
- [ ] Drag/swipe работает корректно
- [ ] Индикаторы (dots) видны и кликабельны

## 5. Док-панель (Dock)
- [ ] Док-панель всегда внизу экрана (fixed bottom)
- [ ] Не перемещается при смене питомца
- [ ] Не перекрывает контент
- [ ] Учитывает safe-area-inset-bottom
- [ ] Все иконки видны и кликабельны
- [ ] Нет горизонтального скролла на маленьких экранах

## 6. Overflow и Scroll
- [ ] Нет overflow-x на body/html
- [ ] Нет горизонтального скролла на любом размере экрана
- [ ] Вертикальный скролл работает плавно
- [ ] Touch scrolling работает корректно

## 7. Отступы и Padding
- [ ] Контейнеры имеют корректные отступы (px-4, px-6)
- [ ] padding-bottom учитывает высоту dock + safe-area
- [ ] Между элементами достаточно пространства

## 8. Touch Targets
- [ ] Все кнопки минимум 44x44px
- [ ] Кнопки не перекрываются
- [ ] Достаточное расстояние между интерактивными элементами

## 9. Адаптивность
- [ ] Layout корректно работает на всех breakpoints
- [ ] Текст читабелен на всех размерах
- [ ] Изображения масштабируются правильно
- [ ] Нет разрывов в layout

## 10. Производительность
- [ ] Плавные анимации
- [ ] Нет лагов при скролле
- [ ] Нет мерцания при переключении питомцев
