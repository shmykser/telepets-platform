# Telepets WebApp - Архитектура и структура проекта

## 📋 Обзор проекта

**Telepets WebApp** - это современное React приложение для управления виртуальными питомцами в Telegram WebApp. Проект реализует полнофункциональную систему тамагочи с экономикой, рынком, играми и социальными функциями.

### 🎯 Основные возможности:
- **Управление питомцами** - создание, уход, развитие
- **Экономическая система** - монеты, транзакции, покупки
- **Рынок** - аукционы, торговля питомцами
- **Мини-игры** - интеграция с Phaser играми
- **Профиль пользователя** - настройки, статистика
- **Административная панель** - управление системой

**Основные API модули:**
```typescript
// API для питомцев
export const petApi = {
  getSummary: (userId: string) => Promise<PetSummary>
  createPet: (userId: string, name: string) => Promise<CreatePetResponse>
  healthUp: (userId: string, petName: string) => Promise<HealthUpResponse>
  resurrect: (userId: string, petName: string) => Promise<any>
}

// API для экономики
export const economyApi = {
  getWallet: (userId: string) => Promise<Wallet>
  getTransactions: (userId: string) => Promise<Transaction[]>
  getActionCosts: () => Promise<ActionCosts>
}

// API для рынка
export const marketApi = {
  listAuctions: (params: AuctionParams) => Promise<Auction[]>
  createAuction: (data: CreateAuctionRequest) => Promise<Auction>

}

// API для игр
export const gamesApi = {
  saveProgress: (userId: string, petName: string, coins: number) => Promise<any>
  getUserNames: (userIds: string[]) => Promise<UserNameResponse[]>
  getProgress: (userId: string, petName?: string) => Promise<any>
}
```

## 📝 Примечания для разработчика

### **При добавлении новых функций:**
1. **Создайте типы** в `types/index.ts`
2. **Добавьте API методы** в `lib/api.ts`
3. **Создайте хуки** в `hooks/`
4. **Добавьте компоненты** в `components/`
5. **Обновите роутинг** в `App.tsx`

### **При интеграции с играми:**
1. **Создайте адаптер** в `adapters/`
2. **Добавьте хуки** в `hooks/games/`
3. **Создайте компонент** для запуска игры
4. **Настройте postMessage** коммуникацию
5. **Добавьте сохранение прогресса**
