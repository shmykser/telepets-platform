## 📋 Чеклист тестирования

### 1. Функциональное тестирование

#### 1.1. WebSocket подключение
- [ ] WebSocket подключается при загрузке страницы
- [ ] Подключение стабильно (не падает)
- [ ] Автоматическое переподключение при разрыве
- [ ] Только одно подключение (singleton)
- [ ] Heartbeat работает (ping/pong каждые 30 сек)

#### 1.2. Получение данных через WebSocket
- [ ] Первоначальные данные приходят при подключении
- [ ] Обновления приходят при изменениях:
  - [ ] Создание нового питомца (`pet_created`)
  - [ ] Изменение здоровья (`health_changed`)
  - [ ] Переход стадии (`stage_changed`)
  - [ ] Обновление кошелька (`wallet_updated`)
  - [ ] Обновление аукционов (`auctions_updated`)

#### 1.3. Polling отключен при WebSocket
- [ ] Нет запросов к `/api/summary/all` при активном WebSocket
- [ ] Нет запросов к `/api/summary` при активном WebSocket
- [ ] Нет запросов к `/api/economy/wallet` при активном WebSocket
- [ ] Нет запросов к `/api/market/auctions` при активном WebSocket
- [ ] Polling возобновляется при отключении WebSocket (fallback)

#### 1.4. Redis кеширование
- [ ] Данные кешируются на бэкенде
- [ ] ETag работает (304 Not Modified при неизменных данных)
- [ ] Кеш инвалидируется при изменениях
- [ ] Кеш TTL работает корректно

### 2. Производительность

#### 2.1. Снижение количества запросов
- [ ] Проверить количество запросов в Network tab:
  - [ ] До оптимизации: ~24 запроса/мин
  - [ ] После оптимизации: ~2 запроса/мин (только при изменениях)
  - [ ] Снижение на ~90%

#### 2.2. Задержка обновлений
- [ ] Обновления приходят мгновенно через WebSocket
- [ ] Нет задержки 5-10 секунд как при polling
- [ ] UI обновляется сразу при изменениях

#### 2.3. Работа Phaser игр
- [ ] Игры не тормозят при обновлениях данных
- [ ] FPS остается стабильным (60 FPS)
- [ ] Нет блокировок event loop
- [ ] Игры работают плавно даже при частых обновлениях

### 3. Кроссбраузерная совместимость

- [ ] Chrome/Chromium
- [ ] Firefox
- [ ] Safari (если доступно)
- [ ] Edge
- [ ] Мобильные браузеры (iOS Safari, Chrome Mobile)

### 4. Нагрузочное тестирование

#### 4.1. Множественные подключения
- [ ] 10 одновременных пользователей
- [ ] 50 одновременных пользователей
- [ ] 100 одновременных пользователей
- [ ] Сервер не падает под нагрузкой

#### 4.2. Частые обновления
- [ ] Система обрабатывает частые изменения
- [ ] WebSocket стабилен при высокой нагрузке
- [ ] Redis кеш работает эффективно

### 5. Обработка ошибок

- [ ] Graceful fallback на polling при ошибке WebSocket
- [ ] Обработка ошибок подключения
- [ ] Обработка ошибок Redis (система работает без кеша)
- [ ] Логирование ошибок
